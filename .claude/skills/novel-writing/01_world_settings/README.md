# 01 — World Settings

世界观设定与背景资料。

## 用途

此目录存放小说世界的所有设定信息，为一致性写作提供基础。

## 建议包含的设定维度

- **地理** — 大陆、国家、城市、地标、地形
- **历史** — 重大历史事件、纪元划分、王朝更替
- **力量体系** — 修炼/魔法/科技体系、等级划分、能力描述
- **社会结构** — 种族、阶级、政治体制、经济体系
- **文化** — 宗教信仰、风俗习惯、语言文字、节日庆典
- **组织势力** — 宗门/公会/家族/军团等重要组织
- **物品道具** — 重要武器、法宝、道具的设定
- **生物种族** — 特殊生物、怪物、灵兽等

## 推荐文件结构

```
01_world_settings/
├── README.md
├── world_overview.md       # 世界观总览（快速参考）
├── geography.md            # 地理设定
├── history.md              # 历史年表
├── power_system.md         # 力量/修炼体系
├── factions.md             # 组织势力
├── culture.md              # 文化与社会
├── items.md                # 重要物品
└── creatures.md            # 生物种族
```

## 注意事项

- 每次写作前应快速回顾 `world_overview.md` 以确保设定一致
- 新增设定时同步更新总览文件
- 避免设定冲突，如有矛盾应及时标注并解决
