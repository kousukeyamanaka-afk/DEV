# 02 — Characters

角色档案与人物关系。

## 用途

此目录存放所有角色的详细档案，以及角色之间的关系图谱。

## 角色档案模板

每个重要角色创建一个独立文件，包含以下信息：

```markdown
# 角色名

## 基本信息
- **全名**: 
- **别名/称号**: 
- **年龄**: 
- **性别**: 
- **种族**: 
- **身份/职业**: 

## 外貌描写
- **体型**: 
- **面部特征**: 
- **标志性特征**: 
- **常见装扮**: 

## 性格特质
- **核心性格**: 
- **优点**: 
- **缺点**: 
- **口头禅/说话方式**: 
- **习惯动作**: 

## 背景故事
（角色的过去经历，塑造其性格的关键事件）

## 动机与目标
- **核心动机**: 
- **短期目标**: 
- **长期目标**: 
- **内心冲突**: 

## 能力与实力
- **当前等级/实力**: 
- **特殊能力**: 
- **战斗风格**: 
- **成长轨迹**: 

## 人物弧光
- **起点状态**: 
- **关键转变**: 
- **终点状态**: 

## 关键关系
- **与XX**: （关系描述）
```

## 推荐文件结构

```
02_characters/
├── README.md
├── character_list.md       # 角色索引（所有角色速查表）
├── relationships.md        # 人物关系图谱
├── protagonist_name.md     # 主角档案
├── heroine_name.md         # 女主档案
├── villain_name.md         # 反派档案
└── supporting/             # 配角目录
    ├── char_a.md
    └── char_b.md
```

## 注意事项

- 角色分为 **主要角色** 和 **次要角色**，详细程度可不同
- 随情节推进更新角色状态（等级、关系变化等）
- 保持角色言行与性格设定一致
