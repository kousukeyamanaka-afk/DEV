# 03 — Plot Control

主线剧情与支线控制。

## 用途

此目录管理小说的宏观叙事结构，包括主线、支线、时间线和关键转折点。

## 核心内容

### 主线剧情
- **核心冲突** — 整部小说围绕的中心矛盾
- **主题** — 小说想要表达的核心思想
- **三幕结构**（或自定义结构）：
  - 第一幕：建置（世界观展示、角色登场、冲突引入）
  - 第二幕：对抗（升级、挫折、成长、转折）
  - 第三幕：解决（高潮、决战、结局）

### 支线管理
每条支线记录：
- 支线名称与简介
- 涉及角色
- 起始章节 → 结束章节
- 与主线的交汇点
- 当前状态（进行中 / 已完结 / 搁置）

### 关键节点
列出所有重大剧情转折点，包括：
- 章节位置
- 事件描述
- 影响范围
- 情绪基调转变

## 推荐文件结构

```
03_plot_control/
├── README.md
├── main_plot.md            # 主线剧情概览
├── subplots.md             # 支线列表与状态
├── timeline.md             # 故事时间线
├── turning_points.md       # 关键转折点
└── plot_notes.md           # 剧情灵感与备忘
```

## 注意事项

- 每个重大剧情决策应记录在此，避免后续矛盾
- 定期回顾支线状态，避免"弃坑"
- 伏笔在埋设时就应记录回收计划
