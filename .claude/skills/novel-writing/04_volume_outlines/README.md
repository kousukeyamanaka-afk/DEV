# 04 — Volume Outlines

卷/篇级大纲。

## 用途

将整部小说按"卷"（或"篇"/"部"）进行宏观划分，每卷包含概要、章节范围与情感曲线。

## 卷大纲模板

```markdown
# 第X卷：卷名

## 基本信息
- **章节范围**: 第XX章 ~ 第XX章
- **预计字数**: XX万字
- **核心主题**: 
- **时间跨度**: 

## 卷概要
（3-5段话描述本卷的整体故事走向）

## 关键事件
1. 事件一：描述
2. 事件二：描述
3. 事件三：描述
...

## 角色发展
- **主角**: 本卷中的成长与变化
- **重要配角**: 本卷中的表现
- **新登场角色**: 

## 情感曲线
起 → 承 → 转 → 合，标注情绪高低点

## 伏笔与呼应
- **本卷埋设的伏笔**: 
- **本卷回收的伏笔**: 

## 与上下卷的衔接
- **承接上卷**: 
- **引向下卷**: 
```

## 推荐文件结构

```
04_volume_outlines/
├── README.md
├── vol_01.md
├── vol_02.md
├── vol_03.md
└── ...
```

## 注意事项

- 先完成卷大纲再细化章节大纲
- 确保卷与卷之间的节奏变化（不要连续高潮或连续低谷）
- 每卷应有独立的阶段性目标与高潮
