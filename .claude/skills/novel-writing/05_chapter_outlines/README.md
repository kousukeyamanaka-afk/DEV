# 05 — Chapter Outlines

章节细纲。

## 用途

为每一章提供详细的写作蓝图，确保正式写作时有据可依。

## 章节细纲模板

```markdown
# 第XXX章：章节名

## 基本信息
- **所属卷**: 第X卷
- **POV角色**: （视角人物）
- **时间**: 
- **地点**: 
- **预计字数**: 3000-4000字

## 章节目标
- **剧情推进**: 本章需要完成的叙事任务
- **角色发展**: 本章中角色的变化
- **读者体验**: 希望读者产生的感受

## 场景列表
### 场景1：场景标题
- **地点**: 
- **在场角色**: 
- **事件**: 概述发生了什么
- **关键对话**: 重要台词方向
- **情绪基调**: 

### 场景2：场景标题
- ...

## 章末钩子
（本章结尾的悬念/吸引读者继续阅读的点）

## 注意事项
- 需要保持一致的设定点
- 需要呼应的伏笔
- 其他写作提醒
```

## 推荐文件结构

```
05_chapter_outlines/
├── README.md
├── chapter_index.md        # 章节索引总表
├── ch_001.md
├── ch_002.md
├── ch_003.md
└── ...
```

## 注意事项

- 细纲应足够详细，让 AI 或作者能据此直接写作
- 每章开头应自然衔接上一章结尾
- 标注本章涉及的世界观设定，方便写作时参考
