# 07 — Chapter Reviews

章节审阅与修订记录。

## 用途

对已完成的草稿进行系统性审阅，记录问题与修改建议。

## 审阅维度

| 维度 | 检查要点 |
|------|----------|
| **连续性** | 与前后章节的衔接、设定是否一致 |
| **节奏感** | 叙事节奏是否合理、是否拖沓或过快 |
| **角色表现** | 言行是否符合角色设定、对话是否自然 |
| **文笔质量** | 描写功力、遣词造句、修辞运用 |
| **情感传达** | 是否成功营造了目标情绪氛围 |
| **悬念钩子** | 章末是否有吸引力、是否留下悬念 |
| **世界观一致性** | 涉及的设定是否与世界观文件一致 |

## 审阅报告模板

```markdown
# 审阅：第XXX章

## 基本信息
- **审阅版本**: ch_XXX_draft.md
- **审阅日期**: 2026-04-10
- **状态**: pending → in-review → revised → approved

## 总评
（1-2段整体评价）

## 优点
1. ...
2. ...

## 问题与建议

### 🔴 严重问题（必须修改）
1. **问题描述** — 修改建议

### 🟡 一般问题（建议修改）
1. **问题描述** — 修改建议

### 🟢 小问题（可选修改）
1. **问题描述** — 修改建议

## 连续性检查
- [ ] 与上一章衔接正常
- [ ] 角色状态与前文一致
- [ ] 世界观设定无矛盾
- [ ] 伏笔处理正确

## 修订记录
| 日期 | 修订内容 | 版本 |
|------|----------|------|
| | | |
```

## 推荐文件结构

```
07_chapter_reviews/
├── README.md
├── review_ch_001.md
├── review_ch_002.md
└── ...
```

## 注意事项

- 每章至少完成一轮审阅后才能标记为定稿
- 审阅时应参照 `08_style_control` 中的风格规则
- 严重问题必须解决后才能审阅通过
