# 08 — Style Control

写作风格指南与文风规则。

## 用途

定义并维护全书统一的写作风格，确保 AI 辅助写作和人工写作保持一致的文风。

## 核心风格维度

### 叙事视角
- **人称**: 第一人称 / 第三人称有限 / 第三人称全知 / 多视角
- **时态**: 过去时 / 现在时

### 语言风格
- **文风基调**: 轻松幽默 / 严肃沉稳 / 热血激昂 / 细腻唯美 / 简洁冷硬
- **句式偏好**: 长句为主 / 短句为主 / 混合节奏
- **词汇水平**: 通俗易懂 / 文雅古风 / 专业术语丰富
- **修辞偏好**: 哪些修辞手法常用、哪些避免

### 对话风格
- **对话占比**: 对话密集型 / 叙述为主
- **对话标记**: 使用频率与样式
- **角色语言差异化**: 不同角色的说话方式

### 描写规则
- **动作描写**: 详细程度与节奏
- **环境描写**: 频率与篇幅
- **心理描写**: 深度与方式
- **战斗/冲突描写**: 风格与节奏

### 禁忌清单
列出不应使用的表达方式：
- 重复使用的词汇/短语
- 不合时宜的现代用语（如古风设定中）
- 过于直白或过于晦涩的表达

## 风格参考示例

```markdown
## ✅ 好的示例
（粘贴一段体现目标风格的范文）

## ❌ 避免的示例
（粘贴一段需要避免的写法）
```

## 注意事项

- 风格规则应在项目初期确定，避免中途剧变
- AI 写作时将此文件作为系统提示的一部分
- 审阅章节时以此为评判标准
