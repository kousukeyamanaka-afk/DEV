# O Jardim — V2 em andamento

Como continuar no Claude Code (nuvem):

1. Este repositório precisa estar no GitHub (pode ser privado).
2. Abra o Claude Code em claude.ai/code (ou na aba Code do app do Claude), selecione este repositório e peça:

> Leia o CLAUDE.md e escreva a Parte IV (capítulos 12 a 15) seguindo o docs/ROTEIRO_V2.md. Rode as métricas, gere o docx da Parte IV e abra um PR com o resumo e as decisões novas.

3. Revise o PR (o .docx fica em `saidas/`). Depois repita com a Parte V, a Parte VI e o epílogo.

Arquivos: `manuscrito/` (texto da V2 por capítulo), `docs/` (estilo, bíblia de continuidade, roteiro), `tools/` (montagem do .docx e métricas), `referencia/` (V1 original), `saidas/` (.docx gerados).
